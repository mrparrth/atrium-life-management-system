# Update README Documentation

Follow this procedure to sync `README.md` with the latest codebase state:

1. **Analyze Codebase State**:
   - Inspect key configuration files (`package.json`, `pyproject.toml`, `.env.example`, Dockerfiles, etc.).
   - Scan primary directory structure to identify newly added features, CLI commands, or API routes.

2. **Audit `README.md`**:
   - Locate `README.md` in the project root (create it if missing).
   - Check if prerequisite setups, installation steps, scripts, or environmental variables have changed.

3. **Update Documentation**:
   - Update project summary, tech stack, dependencies, and setup/installation steps.
   - Clarify or update code examples and CLI options to match the latest implementation.
   - Maintain clear headings, badge badges if applicable, and logical structure without altering custom hand-written sections.
